## O que é Python?

Python é uma linguagem de programação de alto nível projetada com um foco central na legibilidade do código, o que permite 
aos desenvolvedores expressar conceitos complexos em menos linhas de código do que seria necessário em linguagens como C++ ou Java

---

## Principais características

- Sintaxe clara e legível
- Multiparadigma
- Versatilidade
- Independência de plataforma
