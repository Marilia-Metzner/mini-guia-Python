# 📚 Caderno Temático
Este repositório apresenta um caderno temático desenvolvido com apoio do NotebookLM para aprofundar os estudos sobre a programação em Python;
O mini guia de estudos em Python pode produzir resumos, responder perguntas e criar materiais de revisão.

## 🔎 Objetivos
- Compreender os principais conceitos do tema;
- Ajudar os iniciantes a programarem em Python;
- Material de estudo rápido e prático;
- Ser um material de revisão e estudo avançado em Python.
